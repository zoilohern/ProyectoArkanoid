# ProyectoArkanoid
 
Proyecto de aplicación web con un juego Arkanoid con aprendizaje por refuerzo por parte de los jugadores no controlables, con opción de controlar uno de ellos, acelerar aprendizaje y descargar resultados.

Web Application project including an Arkanoid game applying reinforcement learning in computer players, with additional options including controlling a player, accelerating learning and donwloading results.
